# Date Stamper · 日期标记

一个 Obsidian 插件：**识别当前日期与时间，按你设定的格式，插入到笔记的指定位置。**

设定一次格式，之后无论写日记、记录实验数据还是做设计日志，按一个快捷键就能得到格式统一的日期时间串。

```
日记-2026-10-05-21点41-WK41-周一
```

---

## 一、安装

### 方式 A：直接使用（无需 Node.js）

1. 在你的 Vault 目录下找到（没有就新建）：

   ```
   <你的Vault>/.obsidian/plugins/
   ```

2. 把 `date-stamper` 文件夹放进去（名字必须和 `manifest.json` 里的 `id` 一致）：

   ```
   <你的Vault>/.obsidian/plugins/date-stamper/
   ├── manifest.json
   ├── main.js
   └── styles.css
   ```

   > 只需要这三个文件，其余是源码和构建脚本。

3. 重启 Obsidian（或 `Ctrl+P` → `Reload app without saving`）。
4. 打开 **设置 → 第三方插件 → 已安装插件**，找到 **Date Stamper** 并启用。

### 方式 B：从源码构建

```bash
npm install
npm run build     # 类型检查 + 打包出 main.js
npm run dev       # 开发模式，改代码自动重编译
```

> 若 `npm install` 后报 `The package "@esbuild/win32-x64" could not be found`，
> 执行 `npm install --no-save @esbuild/win32-x64@0.25.5` 补装平台二进制。

### 自检

```bash
node --experimental-strip-types verify.mts
```

51 项断言：ISO 周数跨年边界、中文星期、中文时间、标题定位（含跳过 frontmatter / 代码块）、
H1 标题改写与重复执行去重、格式迁移、文件名安全化。

## 二、使用

### 命令（`Ctrl+P` 打开命令面板）

| 命令 | 说明 |
| --- | --- |
| 插入日期（按设置中的位置） | 主命令，按设置里的「插入位置」执行 |
| 插入日期到光标处 | 有选中文字时直接替换 |
| 插入日期到笔记开头 | 插到第一行之前 |
| 插入日期到笔记末尾 | 追加到最后一行之后 |
| **插入日期到笔记标题（H1）里** | 把 H1 标题本身改成带日期的 |
| 插入日期到指定标题的下一行 | 配合设置里的「目标标题名」 |
| 插入日期到第一个标题的下一行 | 不管标题叫什么，认第一个 |
| 插入日期到笔记中的标记处 | 找标记并替换 |
| 复制格式化日期到剪贴板 | 只复制，不改笔记 |
| 用当前日期重命名当前文件 | 按格式串重命名，保留目录与扩展名 |

左侧功能区的**日历图标** = 主命令。建议给主命令绑快捷键：**设置 → 快捷键**，搜 `Date Stamper`。

### 插入位置一览

| 位置 | 说明 |
| --- | --- |
| 光标处 | 最常用；有选中内容则替换 |
| 笔记开头 / 末尾 | 适合每天都在同一篇里追加记录 |
| **笔记标题（H1）本身** | 把 `# 日记` 变成 `# 日记-2026-10-05-21点41-WK41-周一` |
| **指定标题的下一行** | 例：笔记里有 `## 日期`，日期插到它下面 |
| **第一个标题（H1）的下一行** | 标题名会变也无所谓，认第一个 `#` 标题 |
| **替换笔记里的标记** | 模板首选，见下方「标记替换」 |
| 重命名当前文件 | 实验性；同名文件存在时会拒绝覆盖 |

### 笔记标题（H1）的处理

选「笔记标题（H1）本身」后，插件会把**标题行自身**改掉（不是插到它下面）。

两种处理方式：

| 方式 | `# 我的记录` 的结果 |
| --- | --- |
| **追加**（默认） | `# 我的记录-日记-2026-10-05-21点41-WK41-周一` |
| **替换** | `# 日记-2026-10-05-21点41-WK41-周一` |

追加模式保留原标题文字，用「标题连接符」（默认 `-`）把日期接在后面。

**重复执行不会累积**：插件认得自己盖过的「日期章」——
标题里已有一段以格式串字面前缀开头、后面紧跟数字的日期串时，会**替换那一枚**而不新增。
所以同一天跑三次也不会变成 `# 日记-2026-…-日记-2026-…-日记-2026-…`。

| 原标题 | 执行后 |
| --- | --- |
| `# 日记` | `# 日记-2026-10-05-21点41-WK41-周一` |
| `# 我的记录` | `# 我的记录-日记-2026-10-05-21点41-WK41-周一` |
| 再跑一次（22:11） | `# 我的记录-日记-2026-10-05-22点11-WK41-周一` |

设置面板里这一项有实时示例，改格式串时可以直接看到效果。

查找顺序：第一个 H1 → 没有 H1 就用第一个任意级标题（保留其级别）→ 都没有则在笔记最开头新建 `# 日期串`。
同样会跳过 YAML 属性区和代码块。

### 标题定位的几个坑（已处理）

- 会**跳过 YAML 属性区**和**围栏代码块**，代码示例里的 `# xxx` 不会被误当成标题
- 标题**结尾多写 `#`** 也认，例如 `## 日期 ##`
- 标题名里的 `.` `(` `)` 等正则特殊字符不会炸
- **精确匹配 vs 包含匹配**：
  - 精确：整行标题必须等于你填的文字。`## 今日记录 A` 不会被 `今日记录` 命中
  - 包含：标题里含这几个字就算命中。适合标题带日期后缀的情况
- 如果还是找不到，可在设置里打开 **「找不到标题时自动创建」**，
  插件会在文末新建 `## 目标标题名` 并把日期写在下面（而不是默默插到开头）

> **为什么之前「插不进去」？** 大概率是标题名没对上（比如实际是 `## 日记 2026-10-05`，
> 而设置里填的是 `日期`）。现在可以换成**包含匹配**，或直接改用下面的**标记替换**。

### 标记替换（推荐给固定模板）

在笔记模板里写一个标记，例如：

```markdown
# 实验记录

日期：{{日期}}
```

设置里把「插入位置」选为 **替换笔记里的标记**，「标记文本」填 `{{日期}}`。
之后在这个笔记里执行命令，`{{日期}}` 就会被替换成 `日记-2026-10-05-21点41-WK41-周一`。

- **保留标记 = 关**（默认）：标记被替换掉，一次性填充
- **保留标记 = 开**：日期插在标记**前面**，标记留在原处，下次运行在同一处再追加一条，
  适合做「每次记录都排在同一位置」的日志

### 插入内容模板

设置里的「插入内容模板」中，`{{date}}` 会被替换为格式串算出的结果。

| 模板 | 插进去的内容 |
| --- | --- |
| `{{date}}` | `日记-2026-10-05-21点41-WK41-周一` |
| `# {{date}}` | 一级标题 |
| `> 记录于 {{date}}` | 引用块 |
| `\| 时间 \| 说明 \|` 之类表格行 | 适合往表格里塞时间戳 |

> 模板里若忘了写 `{{date}}`，插件会把日期自动拼在末尾，不会出现「什么都没插入」的空操作。

## 三、可用占位符

格式串用 `{{占位符}}` 拼接。**未识别的占位符会原样保留**，方便排错。

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{YYYY}}` / `{{YY}}` | 四位 / 两位年 | 2026 / 26 |
| `{{MM}}` / `{{M}}` | 月份（补零 / 不补零） | 10 / 10 |
| `{{DD}}` / `{{D}}` | 日期（补零 / 不补零） | 05 / 5 |
| `{{WW}}` / `{{W}}` | 周数（补零 / 不补零） | 41 / 41 |
| `{{周}}` / `{{CN_WD}}` | 中文星期简写 | 周一 |
| `{{CN_WD_FULL}}` | 中文星期全称 | 星期一 |
| `{{WD}}` | 星期数字 1~7（周一 = 1） | 1 |
| `{{EN_WD}}` / `{{EN_WD_FULL}}` | 英文星期简写 / 全称 | Mon / Monday |
| `{{WEEK_CN}}` | 中文周数 | 第41周 |
| `{{Q}}` | 季度 | 4 |
| **`{{CN_TIME}}`** | **中文时间（时+点+分）** | **21点41** |
| `{{CN_TIME_FULL}}` | 中文时间带「分」 | 21点41分 |
| `{{CN_TIME_SEC}}` | 中文时间到秒 | 21点41分30秒 |
| `{{TIME_CN}}` | 时分（冒号） | 21:41 |
| `{{HH}}` / `{{hh}}` | 24 制 / 12 制小时（两位） | 21 / 09 |
| `{{mm}}` / `{{ss}}` | 分 / 秒 | 41 / 30 |
| `{{A}}` / `{{a}}` | 上午下午 / AM PM | 下午 / PM |
| `{{DATE}}` | 等于 `YYYY-MM-DD` | 2026-10-05 |
| `{{TIME}}` | 等于 `HH:mm:ss` | 21:41:30 |
| `{{DATETIME}}` | 等于 `YYYY-MM-DD HH:mm:ss` | 2026-10-05 21:41:30 |
| `{{ISO}}` | ISO 8601（含时区） | 2026-10-05T21:41:30+08:00 |
| `{{TZ}}` | 时区偏移 | +08:00 |
| `{{TS}}` | 紧凑时间戳 | 20261005214130 |
| `{{UNIX}}` | Unix 秒级时间戳 | 1759671690 |

设置面板里有一张**带实时取值**的速查表，不用记。

## 四、关于周数 `{{WW}}`

默认使用 **ISO 8601** 口径：**周一为一周之始，包含当年第一个周四的那一周为第 1 周。**
这是 Excel 的 `ISOWEEKNUM`、Python 的 `date.isocalendar()` 采用的标准。

用例：`2026-10-05` 是周一 → **`WK41`**。
（已通过 5 组跨年边界断言：2025-12-29 → 第1周、2026-01-05 → 第2周、2027-01-01 → 第53周。）

设置里另提供 **「简单周」** 口径（1 月 1 日起每满 7 天算一周，2026-10-05 → 第40周）。

## 五、文件结构

```
obsidian-date-stamper/
├── manifest.json          # 插件元信息（id / 版本 / 最低 Obsidian 版本）
├── main.js                # ★ 构建产物，Obsidian 实际加载的文件
├── styles.css             # 设置面板样式（用主题变量，自动适配明暗）
├── versions.json          # 版本 → 最低 App 版本映射
├── package.json
├── tsconfig.json
├── esbuild.config.mjs
├── verify.mts             # 自检脚本（51 项断言）
└── src/
    ├── main.ts            # 插件主体：命令注册、插入逻辑
    ├── settings.ts        # 设置项定义 + 设置面板 UI
    ├── dateformat.ts      # 日期格式化引擎（纯 JS Date，不依赖 moment）
    └── matchers.ts        # 标题定位纯函数（跳过 frontmatter / 代码块）
```

**日期引擎不依赖 moment.js**，全部用原生 `Date` 实现，避免不同 Obsidian 版本的类型/运行时差异。
`matchers.ts` 与 `dateformat.ts` 都不 import `obsidian`，因此可以被 Node 直接跑测。

## 六、升级说明

- **1.0.0 → 1.1.0**：默认格式自动从 `日记-{{YYYY}}-{{MM}}-{{DD}}-WK{{WW}}-{{CN_WD}}`
  升级为带时间的 `…-{{CN_TIME}}-…`。
  **只有原样保留旧默认值的用户会被自动升级**；你自己改过的格式一律不动。
  想手动切回：设置里点「恢复默认」，或自己把 `{{CN_TIME}}` 加进格式串。

## 七、常见问题

**Q：插入后日期不对？**
看设置面板顶部的**实时预览**，格式串的效果在那里立刻可见。确认无误再插入。

**Q：标题里没插进去 / 插到了别的地方？**
- 想改标题本身 → 「插入位置」选 **笔记标题（H1）本身**
- 想插在标题**下面** → 选「指定标题的下一行」，并把「标题匹配方式」改成**包含即匹配**试试
- 都不行 → 改用「替换笔记里的标记」模式，最稳

**Q：想在文件名里也带上日期？**
「用当前日期重命名当前文件」命令用的是**格式串**（不含内容模板）。
目前是整体替换为日期，需要「原文件名 + 日期」的前缀/后缀模式可以告诉我，我加个选项。

**Q：改了设置要重启吗？** 不用，所有设置即时生效。
